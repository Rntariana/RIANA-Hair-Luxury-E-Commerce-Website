# RIANA-Hair-Luxury-E-Commerce-Website
A responsive e-commerce website designed and developed for a luxury hair brand. The website features product categories, product browsing, responsive layouts, shopping functionality, and WhatsApp-based customer ordering.

RIANA Hair is a modern, responsive e-commerce website created for a luxury hair brand.

## Features

- Responsive design
- Luxury black, pink and neutral colour palette
- Product category navigation
- Hair product catalogue
- Product details
- Shopping cart
- WhatsApp ordering
- Search and filtering
- Mobile-friendly interface
- Interactive JavaScript components

## Hair Categories

- Bodywave
- Crimps
- Futura Fibre
- Headband Wigs
- Human Hair Blends
- Straight Wigs
- Full Frontals
- Glueless Wigs
- Latisha Dupe
- Wig Caps
- Accessories

- HTML5
- CSS3
- JavaScript
- GitHub

This project demonstrates my ability to design and develop a real-world e-commerce interface while focusing on responsive design, user experience and interactive functionality.
